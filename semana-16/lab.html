El Reto de Hoy: tu Propia Cámara, no un Dataset Descargado

A diferencia de las prácticas anteriores (que usaban un dataset ya armado), hoy TÚ eres el dataset: vas a capturar una foto con tu propia cámara y aplicarle todo el flujo de Visión por Computadora visto en clase. Google Colab corre en un servidor en la nube — no tiene una cámara conectada — así que usamos un pequeño truco en JavaScript que le pide prestada la cámara a TU navegador, toma la foto, y se la entrega a Python como un archivo normal.

Haar Cascade (OpenCV)
Un detector de rostros clásico, rápido y liviano — no necesita instalar nada adicional. Solo detecta: encuentra DÓNDE está la cara.
InsightFace (buffalo_l)
Un modelo más moderno y pesado, ya entrenado con millones de rostros. Además de detectar, estima edad y sexo aproximados.
⚠️ Importante: la edad y el sexo que reporta InsightFace son ESTIMACIONES basadas en apariencia, no un dato verificado ni un documento de identidad. Úsalo con espíritu crítico, no como una verdad absoluta.

Parte 1 — Habilitar la Cámara y Capturar una Foto

~10 min · Dado
Celda 1.1 — Dado: función para capturar una foto con tu cámara
def tomar_foto(nombre_archivo='mi_foto.jpg', calidad=0.8):
    js = Javascript('''
    async function tomarFoto(calidad) {
      const div = document.createElement('div');
      const boton = document.createElement('button');
      boton.textContent = '📸 Capturar foto';
      div.appendChild(boton);

      const video = document.createElement('video');
      video.style.display = 'block';
      const stream = await navigator.mediaDevices.getUserMedia({video: true});

      document.body.appendChild(div);
      div.appendChild(video);
      video.srcObject = stream;
      await video.play();

      await new Promise((resolve) => boton.onclick = resolve);

      const canvas = document.createElement('canvas');
      canvas.width = video.videoWidth;
      canvas.height = video.videoHeight;
      canvas.getContext('2d').drawImage(video, 0, 0);
      stream.getVideoTracks()[0].stop();
      div.remove();
      return canvas.toDataURL('image/jpeg', calidad);
    }
    ''')
    display(js)
    datos = eval_js('tomarFoto({})'.format(calidad))
    binario = b64decode(datos.split(',')[1])
    with open(nombre_archivo, 'wb') as f:
        f.write(binario)
    return nombre_archivo

print("✅ Función tomar_foto() lista")
